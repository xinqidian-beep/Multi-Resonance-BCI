# Multi-Resonance-BCI

**多维共振率闭环神经调控框架**  
—— 基于 EEG + 多生理信号 + GVS 的自适应情绪-感知调控系统

专为 VR / 恐怖游戏设计，实现**恐惧可控、平衡稳定、触感增强**的沉浸式体验。

### 核心创新点
- **多维共振率 R (Multi-dimensional Resonance Rate)** 理论模型
- **±2048 整数定标 + Q11.0 定点数方案**（彻底消除浮点累积误差）
- 支持**恐惧、平衡感、触感**等多维度自组织闭环调控
- 理论研究 + 工程落地双导向
