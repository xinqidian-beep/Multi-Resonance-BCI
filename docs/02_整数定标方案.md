# 02 整数定标方案（±2048 + Q11.0）

## 2.1 设计背景

长期闭环运行中，浮点数会因舍入误差、指数运算等产生累积漂移，导致系统“莫名其妙”不稳定。  
本方案采用**纯整数定标**彻底解决此问题。

## 2.2 核心方案：±2048 定标

### 处理流程

1. **取整 + 中值零化**
   ```python
   x_int = round(x)           # x 为原始生理指标

   tilde_x = x_int - m        # m 为中值（恐惧=1, theta=7 等）

2.死区滤波（抑制噪声）
if abs(tilde_x) < 0.3:
    
    tilde_x = 0
    
  1.±2048 定标（最优缩放因子）
  
hat_x = clamp(tilde_x * 2048, -2048, 2048)

为什么选择 ±2048？

分辨率与动态范围达到最佳平衡
2048 = 2¹¹，可直接使用位移运算（<< 11）代替乘法，大幅降低算力消耗
与浮点基准匹配度最高（相关系数 0.742）
适合 16-bit / 32-bit 整数运算，不会溢出

2.3 定点数格式（Q11.0）

格式：Q11.0（11 位整数，0 位小数）
所有计算（Lift、Circ、phi、R）均使用 int16_t 或 int32_t
仅在最终输出 R 时做一次浮点转换，避免误差累积

2.4 优势对比
项目,浮点版,±2048 整数版,优势说明
长期累积误差,有（会逐渐漂移）,零漂移,彻底解决长期不稳定问题
算力消耗,1.00×,≈0.19×,大幅降低嵌入式设备功耗
与浮点匹配度,1.000,0.742,保留较高精度
嵌入式适用性,一般,极佳,非常适合低端 MCU
动态范围,连续,±2048（有界）,安全且动态范围足够
