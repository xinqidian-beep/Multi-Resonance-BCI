# 01 理论框架

## 1.1 项目背景

传统 BCI 系统多采用单一指标（例如仅 EEG 或仅瞳孔）进行阈值触发，缺乏对生理信号**动态共振特性**的建模。

本框架提出**多维共振率（Multi-dimensional Resonance Rate, R）**模型，将恐惧、平衡感、触感等生理-感知信号类比为流固耦合振荡系统，实现精细化、自适应的闭环调控。

## 1.2 核心概念

- **共振率 R**：衡量生理信号在当前状态下的能量传递效率。
  - 高 R → 共振高效（可用较少干预获得明显调控效果）
  - 低 R → 能量耗散严重（需加强干预）

- **多维扩展**：从单一恐惧维度扩展到**恐惧 + 平衡感 + 触感**（可继续扩展注意力、疲劳、疼痛等）。

- **整数定标机制**：采用 **±2048 定标 + Q11.0 定点数**，彻底消除浮点数在长期迭代中的累积误差。

## 1.3 系统整体架构
生理信号输入 (EEG θ波 + 瞳孔 + 注视抖动 + IMU + GSR ...)

↓
多维特征提取与中值零化

↓
±2048 定标 + 死区滤波

↓
多维 R 计算 (全整数运算)

↓
自适应控制律 (Kp = f(R))

↓
执行器输出 (GVS 电流 + 触觉马达 + 视觉/听觉反馈)


## 1.4 理论优势

- 符合**自组织临界性（Self-Organized Criticality）**与**耗散结构理论**
- 支持**涌现式自适应**（无需显式全局参数调度）
- 工程上可完全使用整数运算，适合低功耗嵌入式设备
